# Saumya Mathur — Portfolio

A clean, minimal developer portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Assets

- `public/logo.png` — portfolio monogram logo
- `public/favicon.ico` — browser favicon
- `public/resume.pdf` — empty placeholder; replace later
- `public/profile.jpg` — empty placeholder; replace later

Project screenshots can be added inside:

`src/assets/images/`
